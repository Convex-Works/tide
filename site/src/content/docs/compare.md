# Compare tide with Jitsi, Galène, MiroTalk, Zoom and Google Meet

tide does less than the others. It is for teams that want their own meeting server and no more.

|                                   | tide                                    | Jitsi Meet                                        | Galène                                                                             | MiroTalk SFU                                                    | Zoom                                                | Google Meet                                                     |
| --------------------------------- | --------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------- |
| Where it runs                     | Your server                             | Your server, or meet.jit.si                       | Your server                                                                        | Your server                                                     | Zoom's cloud                                        | Google's cloud                                                  |
| Source code                       | Public on GitHub                        | Open source (Apache 2.0)                          | Open source (MIT)                                                                  | Open source (AGPL-3.0), or a paid commercial licence            | Closed                                              | Closed                                                          |
| Processes to run                  | 1 (3 with recording)                    | 4 (and 1 more per recording at the same time)     | 1                                                                                  | 1 Node.js server, with a media worker per CPU core              | None                                                | None                                                            |
| Cost                              | Free. You pay for the server            | Free. You pay for the server                      | Free. You pay for the server                                                       | Free. You pay for the server                                    | Free plan ends meetings at 40 minutes               | Free plan ends meetings of 3 or more at 60 minutes              |
| People in one meeting             | As many as one server holds             | Many servers can share a meeting                  | As many as one server holds, about 20 per core on video                            | As many as one server holds                                     | 100 free, up to 1,000 with an add-on                | 100 free, up to 1,000 on Enterprise plans                       |
| Sign-in for hosts                 | Any OIDC provider, or none              | JWT, LDAP or local accounts. OIDC with an adapter | Group passwords, invite tokens or an external auth server                          | OIDC, JWT, or usernames and passwords in its config             | Zoom account. SAML on paid plans                    | Google account. SAML through Workspace                          |
| Guests                            | Link, no account. Optional lobby        | Link, no account. Optional lobby                  | Invite link or password. No lobby; a group can stay locked until an operator joins | Link, no account. Optional lobby                                | Link, no account. Waiting room                      | Link. Without a Google account, the host lets them in           |
| Recording                         | On the server, to your S3 bucket        | On the server with Jibri, or in the browser       | On the server, as WebM files on its disk                                           | In the browser. Saved locally, or uploaded to the server or S3  | On your computer. To the cloud on paid plans        | To Google Drive, on paid plans                                  |
| Transcripts                       | Optional, on the host's own Mac (alpha) | With Jigasi and a speech service                  | With galene-stt (Whisper), on any machine that joins                               | In the browser's speech service, or a Whisper API you configure | In the cloud, on paid plans                         | In the cloud, on paid plans                                     |
| End-to-end encryption             | No. Your server decrypts the media      | Optional, in supported browsers                   | No. Your server decrypts the media                                                 | No. Your server decrypts the media                              | Optional. Turns off cloud recording and AI features | Encrypted in transit. Client-side encryption on some paid plans |
| Apps                              | Browser only                            | Browser, desktop, iOS, Android                    | Browser. Android app for audio and screen sharing                                  | Browser only                                                    | Desktop, iOS, Android, browser                      | Browser, iOS, Android                                           |
| Phone dial-in                     | No                                      | With Jigasi                                       | With galene-sip (experimental)                                                     | In-room SIP calling (experimental)                              | Yes                                                 | On paid plans                                                   |
| Background blur                   | No                                      | Yes                                               | Yes                                                                                | Yes                                                             | Yes                                                 | Yes                                                             |
| Breakout rooms, polls, whiteboard | No, by design                           | Yes                                               | No                                                                                 | Yes                                                             | Yes                                                 | Some, on paid plans                                             |
